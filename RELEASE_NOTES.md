# Image Compressor v1.0.0 - Release Notes

## 🎉 Что нового

### ⭐ Основные возможности

- ✅ **WebP поддержка** - добавлена полная поддержка WebP формата на входе и выходе
- ✅ **Один exe-файл** - приложение собирается в единый исполняемый файл (~47 МБ)
- ✅ **Drag & Drop** - удобное перетаскивание файлов и папок
- ✅ **GUI интерфейс** - современный интерфейс на PyQt6
- ✅ **Многопоточность** - быстрая обработка множества файлов
- ✅ **Пакетная обработка** - поддержка папок с подпапками

### 📦 Поддерживаемые форматы

**Входные:**

- JPEG (.jpg, .jpeg)
- PNG (.png)
- WebP (.webp) ⭐ **НОВЫЙ!**
- HEIC (.heic)
- HEIF (.heif)
- AVIF (.avif)

**Выходные:**

- WebP (.webp) - рекомендуется по умолчанию
- PNG (.png)
- AVIF (.avif)
- JPEG (.jpg)

## 📥 Установка

### Готовый exe-файл

Скачайте `ImageCompressorGUI.exe` и запустите. Никаких дополнительных установок не требуется!

### Из исходников

```bash
git clone <repository>
cd image_compressor
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python gui_main.py
```

## 🚀 Использование

1. Запустите `ImageCompressorGUI.exe`
2. Перетащите файлы или папки в окно программы
3. Настройте качество (по умолчанию 80%)
4. Выберите формат вывода (по умолчанию WebP)
5. Нажмите "Начать сжатие"
6. Дождитесь завершения обработки

Сжатые файлы сохраняются рядом с оригинальными с суффиксом `_compressed`.
