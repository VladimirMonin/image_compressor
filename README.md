# Image Compressor 🖼️

Современный инструмент для сжатия изображений с GUI интерфейсом и поддержкой множества форматов.

## ✨ Возможности

- **Поддерживаемые входные форматы:** JPG, JPEG, PNG, **WebP**, HEIC, HEIF, AVIF
- **Поддерживаемые выходные форматы:**
  - WebP (.webp) - рекомендуется (отличное сжатие и совместимость)
  - HEIF (.heic) - высокая эффективность сжатия
  - AVIF (.avif) - новейший формат с максимальным сжатием
  - JPEG (.jpg) - универсальный стандартный формат
  - PNG (.png) - без потерь качества
- **GUI интерфейс:** удобный графический интерфейс на PyQt6
- **Drag & Drop:** перетаскивание файлов и папок
- **Пакетная обработка:** рекурсивная обработка папок и подпапок
- **Многопоточность:** быстрая обработка множества файлов
- **Standalone EXE:** собирается в один исполняемый файл

## 🚀 Быстрый старт

### Готовый EXE-файл

1. Скачайте `ImageCompressorGUI.exe` из релизов
2. Запустите файл
3. Перетащите изображения или выберите через диалог
4. Настройте качество и формат
5. Нажмите "Начать сжатие"

## 📖 Использование

### GUI версия (рекомендуется)

```bash
python gui_main.py
```

**Возможности GUI:**

- 📁 **Drag & Drop** - перетащите файлы или папки прямо в окно
- 🎛️ **Настройка качества** - слайдер от 1 до 100%
- 📋 **Выбор формата** - WebP, PNG, AVIF, JPEG
- 📊 **Прогресс в реальном времени** - видите текущий статус
- 📝 **Детальный лог** - вся информация о процессе
- ⏹️ **Остановка процесса** - можно прервать в любой момент
- 🚀 **Многопоточность** - быстрая обработка множества файлов

### Консольная версия

```bash
# Интерактивная версия
python classes.py

# Многопроцессорная версия (быстрее для больших объемов)
python main.py

# GUI версия с drag & drop (рекомендуется!)
python gui_main.py
```

### Запуск через batch-файл (Windows)

- **Консольная версия:** Двойной клик по `run_compressor.bat`
- **GUI версия:** Двойной клик по `run_gui.bat`

# Многопроцессорная версия (для большого количества файлов)

python main.py

```

### Батч-файлы (Windows)

- `run_gui.bat` - запуск GUI версии
- `build_exe.bat` - сборка EXE-файла

## 🔨 Сборка EXE

```bash
# Простой способ
build_exe.bat

# Или вручную
pyinstaller gui_compressor.spec --clean
```

Результат: `dist\ImageCompressorGUI.exe` (~47 МБ)

## 📋 Поддержка форматов

### Входные форматы (что можно сжимать)

| Формат | Расширение | Примечание |
|--------|------------|------------|
| JPEG | .jpg, .jpeg | Стандартный формат фото |
| PNG | .png | Формат с прозрачностью |
| **WebP** | **.webp** | **Современный формат Google** ⭐ |
| HEIF | .heic, .heif | Apple формат |
| AVIF | .avif | Новейший формат |

### Выходные форматы (во что сжимаем)

| Формат | Расширение | Особенности | Рекомендация |
|--------|------------|-------------|--------------|
| **WebP** | **.webp** | **Оптимальное сжатие + совместимость** | **⭐ По умолчанию** |
| PNG | .png | Без потерь, прозрачность | Для графики |
| AVIF | .avif | Максимальное сжатие | Для веба |
| JPEG | .jpg | Универсальная совместимость | Для фото |

## 💡 Советы

- **WebP** - лучший выбор для большинства случаев (сжатие ~30% лучше JPEG)
- **Качество 80-85** - оптимальный баланс размера и качества
- Используйте **Drag & Drop** для удобства
- Приложение сохраняет файлы рядом с оригиналами с суффиксом `_compressed`

## 🔧 Системные требования

- **Python:** 3.10+ (для разработки)
- **ОС:** Windows 10/11, Linux, macOS
- **RAM:** 4 GB минимум
- **Место:** ~50 MB для exe-файла
