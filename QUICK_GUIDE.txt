IMAGE COMPRESSOR — безопасный быстрый старт

Только создание новых проверенных файлов. На принятой границе `68b7dc5` и в готовом
EXE оригиналы и прежние результаты не удаляются и не заменяются; в текущем HEAD
есть непринятый WIP удаления (см. п.4). При занятом имени — ошибка, а не overwrite.

GUI (канонический — PySide6 v2; готовый EXE — без Python):
1. Проще всего без Python/Qt: запустите run_image_compressor_v2.bat или откройте
dist\windows-pyside6\20261023-candidate-02\ImageCompressorV2.exe (Windows x64).
Из исходников: отдельная среда PySide6 v2 по README.md, затем
  <pyside-python> -m gui_pyside6_v2
Старый gui_main.py на PyQt6 — legacy, не рекомендуемый путь.
2. Выберите файлы или папки; GUI раскрывает папки рекурсивно.
3. Выберите WebP/JPEG/HEIF/AVIF и качество (GUI default WebP/80).
4. Удаление оригиналов на принятой границе и в готовом EXE недоступно
   (disabled/unchecked): delete_original=True отвергается до эффектов.
   В текущем HEAD есть непринятый WIP удаления; это не принятая функция
   (см. docs/releases/windows-pyside6-candidate-02.md).
5. При resize укажите обе положительные стороны. Увеличения/crop нет.
6. Нажмите «Начать сжатие» и прочитайте настоящий итог.

Примеры имён:
photo.png -> photo.webp              (оригинал остаётся)
photo.webp -> photo_compressed.webp  (оригинал остаётся)
photo.jpeg -> photo_compressed.jpg  (оригинал остаётся)
Постфикс _small заменяет _compressed при совпадении suffix family.
Точный output в API/CLI не переименовывается автоматически.

Stop только запрашивает cooperative cancellation. Текущий native codec может
долго не отдавать управление; уже допущенная публикация может завершиться.
Окно не фабрикует (0,0), ждёт настоящего завершения QThread перед новым запуском
или закрытием. Уже готовые результаты сохраняются.

CLI (неинтерактивный, после headless install из README.md):
  image-compressor capabilities
  image-compressor convert sample.png --format WEBP --quality 80
  image-compressor convert samples --recursive --max-width 1920 --max-height 1080
Без --recursive CLI обходит только непосредственные файлы каталога.
capabilities/convert: один UTF-8 JSON в stdout, safe diagnostics отдельно в stderr.
Exits: 0 success; 2 rejected/usage; 3 partial; 4 failed; 5 internal/delivery; 130 cancel.
python classes.py convert ... вызывает тот же CLI, больше не задаёт вопросов.

Входы: JPEG, PNG, WebP, HEIF/HEIC, AVIF. PNG только вход, не выход.
Доступность optional codecs проверяется фактически через capabilities.
Alpha JPEG композируется на белый; EXIF/XMP/ICC/comments не переносятся.
Несколько кадров и неоговорённые HDR/16-bit modes отвергаются.

Публикация требует hard links (проверена local NTFS). Нет unsafe fallback,
crash-durability или гарантии меньшего файла. После потери ответа сначала
проверьте известные назначения, не повторяйте вслепую с overwrite.
Старый dist\ImageCompressorGUI.exe не обновлён этой работой; публичный release,
подпись, installer и другие платформы/DPI не квалифицированы.
